# PTM-analyse-master-3.0
Logiciel de calcul automatique pour analyse de marge, tonnage et optimisation opérationnelle dans le secteur du transport.

## Master Pro Max 3.0
Ce dépôt inclut un module Node.js `MasterProMax.js` pour calculer la marge nette, le taux de perte et générer des alertes métier.

### Exemple d'utilisation
```bash
node MasterProMax.js
```

### Export
- `calculateMargePro(data)`
- `validateNumericField(value, fieldName)`
