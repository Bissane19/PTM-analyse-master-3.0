# PTM-analyse-master-3.0

Logiciel de calcul automatique pour l'analyse de marge, le suivi du tonnage et l'optimisation des coûts opérationnels dans le secteur du béton industriel.

## Master Pro Max 3.0
Ce module est conçu pour :
* Calculer la marge nette en temps réel.
* Suivre le taux de perte et optimiser le dosage.
* Générer des alertes métier basées sur la performance.
* S'intégrer facilement via Webhooks ou API (Node.js).

## Technologies
* JavaScript (Node.js)
* Netlify Functions (Architecture Serverless)
* Format de réponse : JSON
